# Трекер расходов

Простое веб-приложение для учёта личных трат: React + Vite на фронте, Express на бэкенде, данные хранятся в SQLite (встроенный `node:sqlite`, без внешних зависимостей).

## Возможности

- Добавление траты (сумма, категория, дата, заметка)
- Список всех трат с удалением
- Сумма по категориям и общая сумма за текущий месяц

## Запуск

Нужен Node.js версии 22.5+ (используется встроенный `node:sqlite`).

```bash
npm install
npm run dev
```

Это единственная команда, которая нужна после установки зависимостей — она поднимает и бэкенд (`http://localhost:3001`), и фронтенд (`http://localhost:5173`) одновременно. Открывайте `http://localhost:5173`.

База данных создаётся автоматически в `server/data.sqlite` при первом запуске.

## Структура проекта

```
expense-tracker/
├── server/    Express API + SQLite
└── client/    React (Vite) фронтенд
```

## API

| Метод  | Путь                | Описание                                  |
|--------|---------------------|--------------------------------------------|
| GET    | /api/expenses        | Список всех трат                          |
| POST   | /api/expenses        | Добавить трату `{amount, category, date, note}` |
| DELETE | /api/expenses/:id    | Удалить трату                             |
| GET    | /api/stats           | Сумма за текущий месяц + разбивка по категориям |
